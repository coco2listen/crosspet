# Claude 常用外观与客户端身份（本地修复）

本轮按用户要求只在本地分支 `codex/claude-outfits-identity` 实现，不推送，不创建或更新 PR。

## 改动

Claude 增加“卫衣”“睡衣”两个常用外观，复用 DeepSeek 彩蛋中已有 Claude 图片。新目录采用现有 skinOf=claude 约定：pop 用于 idle、caught 用于 thinking、pretend 用于 writing、bye 用于 bye；其他动作按原有网页回退规则复用图片。保留 Claude 基础台词与固定客户端身份，不新增绘图，也不改变 DeepSeek 的原彩蛋。衣服选择仍由共享设置管理，两只 Claude 共用所选衣服。

每个客户端页面收到固定 familyClient；状态标签持续显示“终端 / 桌面”，来源 tooltip 使用固定端身份。网页同时拒收其他客户端或其他家族的状态 / 会话；不把来源不明的工作事件猜给某一端。单宠和旧三宠没有客户端限制，保持兼容。

## 排查与实际验证

读取真实状态文件中的元数据后，Swift 聚合未复现客户端串台：TUI / Desktop 记录均仅属于自身，两端当时都为 Idle，所以相同姿态本身不能证明串台。已确认原页面没有固定端身份，旧原生测试还给两端相同动作，缺少异态覆盖。本轮补上固定标识和防错投拦截，不宣称已找到一个未复现的生产者串台错误。

原生异态测试在独立偏好域和状态目录中，让 Claude TUI 为 Thinking/thinking、Desktop 为 Waiting Permission/asking，同时逐窗核对固定标签和渲染姿态。它是隔离合成事件测试，不是真实客户端工作事件；未修改真实任务状态，也未退出 Claude / Codex / DSH。

安装后通过 CUA 读取到真实终端宠标签“终端 · Idle · 状态待确认”。未通过 CUA 完成右键换装操作，不将该动作记为实测通过；换装的原生 bridge / 渲染核验见上述窗口探针。本轮没有重跑真实鼠标拖动、全屏、Windows、Intel 或长时间稳定性测试。
